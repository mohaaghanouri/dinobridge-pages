# https://dinobridge.de/robots.txt
#
# Static marketing site. Nothing here is private, so there is nothing to hide
# from a crawler. robots.txt DEFAULTS TO ALLOW, so the functional content of this
# file is the four lines below plus the Sitemap line — the rest is a written
# record of the AI-crawler decision.
#
# Two things not to change without thinking:
#
# 1. Never add a Disallow here to "help" a noindex. A blocked page cannot be
#    crawled, so its noindex is never read, so it can still be indexed URL-only
#    from external links. noindex requires Allow.
#
# 2. A named user-agent group REPLACES the * group for that bot. If a Disallow is
#    ever added under "User-agent: *", every bot named below silently keeps full
#    access.
#
# 3. Cloudflare's "Managed robots.txt" (AI Crawl Control → Signals) must stay OFF.
#    When on, Cloudflare prepends its own block to the served file — Disallow for
#    GPTBot, ClaudeBot, CCBot, Google-Extended and friends plus a Content-Signal
#    line — which contradicts everything below. It was found on and switched off
#    on 2026-09-07. `curl -s https://dinobridge.de/robots.txt | head` should start
#    with "User-agent: *" and nothing above it.

User-agent: *
